# 捕鱼达人 · 微信小游戏

纯分数制休闲捕鱼游戏，单局 60 秒。按住屏幕拖动即可自动瞄准开火，
连击越高炮台越强，越打越猛。无金币消耗、无兑换，规避赌博类审核风险。

设计与数值方案见 [Document.md](./Document.md)。

## 玩法

- 按住屏幕并移动手指：炮台横向跟随、炮口自动朝向手指持续开火
- 捕获鱼累加 COMBO，2 秒未捕获归零（炮台等级只升不降，最高 8 级）
- 随机道具：气泡漂过屏幕，击落即触发（7 种，各有一套动画，强的为全屏效果）
- 特殊事件：鱼群（25s）、黄金时刻双倍分（35s）、狂暴模式（COMBO 达 30）
- BOSS：大王乌贼（24s）、鲸鱼（40s）、深海龙王（52s）
- 60 秒结算，最高七星（门槛 5000 / 11000 / 20000 / 32000 / 46000 / 62000 / 85000）
  未满三星只展示 3 颗星，三星起多展示一颗空星作为下一目标

## 技术栈

原生微信小游戏 + Canvas 2D（无第三方引擎）。设计分辨率 750×1334，
按屏幕宽度等比缩放并适配安全区。无音频资源，首包极小。

美术分两类：小鱼 / 海草 / 岩石 / 气泡使用 Kenney Fish Pack 2.0 贴图（CC0，见
`assets/img/LICENSE-kenney.txt`）；中大型鱼（河豚、海龟、鲨鱼、黄金鱼、鲸鱼）
参考同一套扁平色阶程序化绘制，保证放大后依然锐利。

## 目录结构

```
├── game.js                      // 入口，预加载贴图后实例化 Main
├── game.json                    // 运行配置（竖屏锁定）
├── assets/img                   // Kenney 贴图（约 74KB，CC0）
├── js
│   ├── config.js                // 全部数值表：鱼类/炮台/时间轴/星级/事件/道具
│   ├── render.js                // 画布与设计坐标系缩放、坐标换算
│   ├── databus.js               // 全局状态管理器（单例）
│   ├── main.js                  // 游戏状态机、主循环、碰撞、输入
│   ├── base
│   │   ├── sprite.js            // 精灵基类（圆形碰撞）
│   │   ├── pool.js              // 对象池
│   │   └── draw.js              // 绘图工具（圆角矩形/星星/格式化）
│   ├── game
│   │   ├── fish.js              // 鱼类（贴图摆尾动画 / 各鱼种程序化绘制、血条）
│   │   ├── bullet.js            // 子弹（水滴 / 重炮炮弹 / 狂暴金色渔网）
│   │   ├── cannon.js            // 炮台（跟随/瞄准/多管/增益光环）
│   │   ├── combo.js             // 连击与炮台等级系统
│   │   ├── fishspawner.js       // 时间轴刷鱼、BOSS 时间表与事件触发
│   │   ├── powerup.js           // 道具气泡（7 种图标）
│   │   ├── powerups.js          // 道具系统（刷新/增益倒计时/雷霆与核弹结算）
│   │   └── effects.js           // 特效层（金币/飘字/光环/速度线/道具全屏动画）
│   └── runtime
│       ├── images.js            // 贴图预加载与缓存（含受击闪白剪影）
│       ├── background.js        // 水体渐变 + 远近两层植被岩石 + 气泡
│       ├── ui.js                // HUD 与准备/结算界面
│       └── audio.js             // 音频管理（默认关闭，放入音频后启用）
```

## 开发与运行

用微信开发者工具打开本项目目录即可预览（compileType 为 game）。

## 后续可扩展

- 音频：将音频文件放入 `audio/` 并把 `js/runtime/audio.js` 的 `ENABLED` 置为 `true`
- 变现与留存：激励视频（结算翻倍/加时）、每日挑战、皮肤收集、好友排行榜、成就系统
  （见 Document.md 第十一节）
